# 🌱 ePlant Shopping Website

ePlant is a simple and user-friendly online shopping website for purchasing indoor and outdoor plants. The application allows users to explore different plants, view their prices and descriptions, add plants to a shopping cart, and manage the items in their cart.

## 📌 Features

- Browse a collection of plants
- Plants organized into different categories
- View plant name, image, description, and price
- Add plants to the shopping cart
- Increase or decrease the quantity of items in the cart
- Remove items from the cart
- View the total number of items in the cart
- Calculate the total cost of the order
- Responsive and easy-to-use interface

## 🛒 Main Components

### Landing Page

The landing page introduces the ePlant shopping website and provides users with an option to start shopping.

### Product Listing

The product listing page displays the available plants. Plants are grouped into categories, and each product displays information such as its name, image, description, and price.

Users can add their preferred plants to the shopping cart.

### Shopping Cart

The shopping cart displays all the plants selected by the user.

Users can:

- Increase the quantity of a plant
- Decrease the quantity of a plant
- Remove a plant from the cart
- View the total number of items
- View the total price
- Continue shopping
- Proceed to checkout

## 🚀 Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the project folder:

```bash
cd eplant-shopping
```

Install the required dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the application in your browser using the local URL displayed in the terminal.

The project demonstrates concepts such as:
